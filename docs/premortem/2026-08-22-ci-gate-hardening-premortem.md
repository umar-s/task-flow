# Premortem: `ci-gate` hardening (1.8.0)

**Дата:** 2026-08-22 · **Объект:** `docs/superpowers/specs/2026-08-21-ci-gate-hardening-design.md`
**Углы:** Исполнитель · Допущения · Клиент · Противник · Будущий поддерживающий · Интеграция
**Формат:** панель из 6 независимых агентов по спеке (чистый контекст, только артефакты);
47 дыр. Панель опровергателей и критик полноты не отработали (лимит сессии) —
триаж и решения приняты владельцем флоу вручную, с проверкой каждого факта в
скретч-репозитории на пине gitleaks 8.30.1.

**Проверено руками** (то, на чём стоят решения; всё воспроизводится за минуту):

| Факт | Проверка | Итог |
|---|---|---|
| gitleaks возвращает **0**, если git внутри него упал | `detect --log-opts="deadbeef..HEAD"` | `0 commits scanned … no leaks found`, rc 0 |
| пустое слово в `--log-opts` | `--log-opts="--text --diff-merges=first-parent "` | `scanned ~0 bytes`, rc 0 |
| `.gitattributes` `-diff` прячет файл от скана | секрет в `*.py -diff` | без `--text` rc 0, с `--text` rc 1 |
| секрет в merge-коммите | `merge --no-ff` + правка | без `--diff-merges` rc 0, с `first-parent` rc 1 |
| `git rev-list` на битом диапазоне | тот же sha | rc 128 (в отличие от gitleaks) |
| GNU grep в C-локали и байты ≥0x80 | `grep -E $'\xe2\x80[\xaa-\xae]'` | не матчит (rc 1); awk (gawk/mawk/busybox) матчит |
| busybox awk и NUL | запись с NUL | обрезает строку по NUL (сканирует меньше, не больше) |
| `diff.external` / `color.ui` / `diff.noprefix` | `git -c … diff -U0` | обнуляют или ломают разбор → нужны `--no-ext-diff`, `--no-color`, явные префиксы |
| gitleaks FTL (битый конфиг) | `--config bad.toml` | rc **1** без отчёта — неотличимо от находки по коду возврата |
| darwin-тарболлы 8.30.1 | скачаны, посчитан sha256 | совпали с `checksums.txt` релиза |

## Принято (закрыто в 1.8.0)

| # | Дыра | Решение |
|---|---|---|
| H-01 | gitleaks rc 0 при сбое git — «fail-closed по rc» не срабатывает | диапазон валидируется `git rev-list` до скана: pre-push, три CI-файла, `check.yml` |
| H-02 | merge-base с default-веткой пропускает незапушенные коммиты на другой локальной ветке | диапазон = `local --not --remotes=<remote>`; merge-base убран совсем |
| H-03 | секрет в merge-коммите невидим для `git log -p` | `--diff-merges=first-parent` во всех диапазонах |
| A-5 / ADV-1 / H-04 | `-diff` в `.gitattributes` ослепляет скан и unicode-guard | `--text` во всех скан-диапазонах; в unicode-guard ещё `--no-ext-diff`, `--no-textconv`, `--no-color`, фиксированные префиксы |
| — | пустое слово в `--log-opts` тихо сканирует ничего | форма `${RANGE:+ $RANGE}` + инвариант в `lint.sh` |
| A-7 | другой awk может не матчить байтовые диапазоны | self-probe перед вердиктом: не поймал эталонные RLO/ZW/tag/BOM → `exit 2` |
| H-05 | пустой `UNICODE_GUARD_EXCLUDE` как ERE матчит всё | исключение применяется только при непустом значении; фикстура |
| ADV-6 | `MIGRATION_DIRS=" "` → «skipping», rc 0 из UI настроек | пустой список → `exit 2`; каждый слой печатает свои эффективные ручки |
| H-08 | `gitleaks dir` FTL = rc 1 → «секрет» вместо «инфра» | вердикт по JSON-отчёту: rc 1 без отчёта → `exit 2`; предпроверка конфига |
| A-3 | pinned-fetch только linux: на macOS качается linux-бинарь → блок каждого push | `uname -s`, darwin-пины (4 суммы), внятный `exit 2` на прочих ОС |
| A-1 / ADV-2 | CODEOWNERS в корне может игнорироваться (GitHub читает `.github/` первым) | владеем всеми тремя локациями; скилл кладёт файл туда, где платформа читает первым |
| ADV-3 | required-check матчится по имени → чужой workflow даёт «зелёный `secret-scan`» | в CODEOWNERS весь `/.github/workflows/`, не только `gate.yml` |
| C-1 / A-2 / INT-7 | `required_approving_review_count: 1` требует ревью на КАЖДЫЙ PR → снимут правило целиком | в рецепте `0` + `require_code_owner_reviews: true`; эффект назван вслух |
| A-4 / ADV-7 / C-4 / INT-4 | `pre-commit install` не ставит pre-push — слой существует только в README | `default_install_hook_types: [pre-commit, pre-push]` + `minimum_pre_commit_version` |
| C-6 | `GATE_PREPUSH_SKIP` в `~/.zshrc` — вечный обход | обход обязан называть sha этого push'а; иначе — скан, с подсказкой точной строки |
| C-7 | selftest красный от git-конфига пользователя (gpgsign, templateDir, hooksPath) | изолированное окружение: `GIT_CONFIG_GLOBAL/SYSTEM=/dev/null`, `--template=`, `core.hooksPath=/dev/null` |
| M-01 / M-02 | резолв gitleaks и base-ref скопирован в 3 файла каждый (уже разошёлся) | `ci/gitleaks-bin.sh`, `ci/base-ref.sh` + инварианты «никто не резолвит сам» |
| M-04 / M-08 | инвентарь payload и список тестов разъезжаются | скилл копирует `ci/` целиком; таблица скриптов в `ci/README.md`; `tests/run.sh` — глоб; линт сверяет |
| M-07 / INT-1 | литерал AWS-формы в payload и тестах → собственный secret-scan краснеет | ключ собирается в рантайме; инвариант в `lint.sh` запрещает литерал в трекнутых файлах |
| M-03 / INT-2 | список gate-джобов в пяти местах; `task` §8 останется со старым | `task` §8 требует джобы из CI-файла репозитория, а не из памяти скилла; линт сверяет три CI-файла и README |
| C-8 / INT-3 | апгрейд 1.7.x → 1.8.0 не описан: перезапись `MIGRATION_DIRS`, дубли хуков | маркер версии payload в `ci/README.md`, раздел «Upgrading», шаг 3b в скилле (мерж по ключу, показ diff, повтор шагов 5–6) |
| C-2 | старые голые маркеры падают, а править закоммиченную миграцию нельзя | `git grep` для поиска до мержа + инструкция «чинит владелец гейта на интеграционной ветке» |
| C-3 | ложные плюсы unicode-guard на i18n/RTL и вставках | inline-токен `unicode-guard:allow`, документированный `UNICODE_GUARD_EXCLUDE` с требованием якоря |
| ADV-4 | маркер с причиной — всё ещё самовыданный аппрув | честно записано: маркер = декларация автора; аппрув — ревью (CODEOWNERS на dirs миграций); строка в 6b-промпт |
| ADV-5 | `gitleaks:allow` — самый дешёвый обход и мы его рекомендуем | «Known limits — the whole gate» + новый пункт 7b в 6b-промпте: новая суппрессия в диффе = finding |
| ADV-8 | «trojan-source» шире, чем набор точек (гомоглифы) | формулировка сужена до bidi/zero-width/tag; гомоглифы — явный residue 6b |
| INT-5 | агент обойдёт заблокированный push (`--no-verify`) | в «Fixed discipline» `task`: агенту запрещены `--no-verify` и `GATE_PREPUSH_SKIP` |
| INT-6 | сам репозиторий не гоняет unicode-guard, а шипит LLM-промпты | шаг в `check.yml` (dogfood) на собственных добавленных строках |
| M-05 | вес `ci-gate/SKILL.md` растёт | команды protected-branch вынесены в `ci/README.md` (он и так копируется в репо); шаг 5 ссылается |
| M-06 | форма маркера в коде и в трёх документах разошлась | линт-инвариант: в шипящихся документах `destructive: approved` только со скобкой |

## Принято как residue (documented, не чинится кодом)

- **`protect --staged` и `-diff`.** Локальный pre-commit-слой не имеет
  `--log-opts`, поэтому файл, помеченный `-diff`, там невидим; ловит CI
  (`--text`) и pre-push. Записано в «Known limits», `.gitattributes` — в CODEOWNERS.
- **`pre-push` обходится** `git push --no-verify`, `core.hooksPath`, клиентом без
  хуков; журнал ловит только честных. Пол — CI-скан. Записано.
- **Гомоглифы / смешанные алфавиты** — не байтовый класс; 6b.
- **`unicode-guard:allow` и `gitleaks:allow`** — намеренные escape hatch'и;
  защита от злоупотребления — видимость в диффе + правило ревью.
- **Ложные плюсы на настоящих бинарях** (случайная байтовая
  последовательность): не пропускаем бинарное содержимое (иначе один NUL или
  form feed выключал бы слой), а помечаем находку подсказкой; лечится
  `UNICODE_GUARD_EXCLUDE` — видимой правкой в репозитории.
- **busybox awk обрезает строку по NUL** — сканирует меньше, не больше; записано.

## Отклонено

- **Пропускать бинарные файлы в unicode-guard** (первый вариант): даёт
  однобайтовый выключатель слоя.
- **`GATE_INLINE_ALLOW=deny` как отдельный слой** над `gitleaks:allow`: дублирует
  работу ревью, а список исключений всё равно редактируется тем же MR;
  ограничились правилом ревью и «Known limits».
- **Полная история с `--text` на каждый push** (вместо инкрементального
  диапазона): O(history) на push и повторный флаг всех легаси-секретов — то, от
  чего инкрементальность и вводилась.
- **Парсер миграций вместо regex** — прежнее решение аудита, не пересматривается.
- **Enforce CODEOWNERS на `umar-s/task-flow`** — решение владельца репозитория,
  не этого релиза (файл добавлен, правило — нет).
